# Malty Telegram Bot 🍻

A fun drinking game bot for Telegram groups.

## Features

- Never Have I Ever
- Truth or Drink
- Kings Cup (virtual version)
- Random drinking challenges
- Player statistics tracking

## Setup

1. Clone this repository
2. Install requirements: `pip install -r requirements.txt`
3. Create `.env` file with your Telegram token
4. Run: `python app.py`

## Deployment

[![Deploy](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy)

## Commands

- `/start` - Show help
- `/join` - Join the game
- `/neverhaveiever` - Start Never Have I Ever
- `/truthordrink` - Start Truth or Drink
- `/kingscup` - Start Kings Cup
- `/randomtask` - Get a random challenge
- `/stats` - Show your stats
- `/endgame` - End current game
